# D. Torque: The King's Game — Game Plan

## Overview
D. Torque is a detective thriller series that follows Detective Torque as he investigates a series of connected crimes that lead to a mysterious mastermind known only as "The King."

## Game Type
- Detective Mystery
- Story-Driven Adventure
- Investigation Game

## Main Character
D. Torque

## Main Objective
Solve each case, uncover hidden clues, identify suspects, and discover the true identity of The King.

## Season 1 Cases

### Episode 1: The Falling Man
A suspicious death starts the investigation.

### Episode 2: The Coffee Cup
A poisoned cup reveals a deeper conspiracy.

### Episode 3: The Missing Witness
A key witness disappears before testifying.

### Episode 4: The Warehouse Fire
Evidence is destroyed in a mysterious fire.

### Episode 5: The Silent Phone
A missing phone contains dangerous secrets.

### Episode 6: The King's Game
Torque finally confronts the mastermind behind the crimes.

## Gameplay Features
